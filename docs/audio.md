# 음악과 박자 컷

모든 영상(행사, 여행, 현장·매장·상품·학교·동아리·졸업, 결산)은 선택 필드 `audio`로 배경 음악을 넣을 수 있다. `audio`가 없으면 영상과 길이 계획은 이전과 완전히 같다.

## props

```json
"audio": {
  "src": "/uploads/3d81a68ddf8b44c74f76.wav",
  "volume": 0.8, "fadeInSec": 1, "fadeOutSec": 2,
  "startFromSec": 0, "loop": true,
  "bpm": 120, "beatOffsetSec": 0.25, "syncCuts": true
}
```

| 필드 | 뜻 |
|---|---|
| `src` | 스튜디오 업로드(`/uploads/…`), `public/` 안의 상대 경로(`media/bgm.mp3`), 또는 https 주소 |
| `volume` | 0~1 |
| `fadeInSec`, `fadeOutSec` | 시작 페이드 인 / 영상 끝에서 자동 페이드 아웃(영상의 마지막 프레임에서 0이 됨) |
| `startFromSec` | 음원의 이 지점부터 재생 |
| `loop` | 영상이 음원보다 길면 반복. 페이드 곡선은 반복과 무관하게 영상 전체 시간축 기준 |
| `bpm` | 분당 박자 수(40~240에서만 박자 맞추기가 동작) |
| `beatOffsetSec` | **음원 파일 안에서** 어느 한 박이 있는 시각. 영상 시간축으로는 `beatOffsetSec - startFromSec`로 환산한다 |
| `syncCuts` | `true`이고 `bpm`이 있으면 사진 컷 전환을 박자에 맞춘다 |

재생은 `src/audio/BgAudio.tsx`가 각 `*Video` 컴포넌트 최상위에서 Remotion `<Audio>`로 한다. 같은 코드로 스튜디오 미리보기(`@remotion/player`)와 MP4 렌더(소리 포함 mux, AAC)가 동작한다.

## 박자 컷 (`planFlow`)

`syncCuts`가 켜지면 `planFlow`(`src/analysis/videoData.ts`)가 사진 컷이 끝나는 시각(전환 와이프가 끝나 새 컷이 자리잡는 프레임)을 **영상 전체 시간축 기준으로 가장 가까운 박**으로 옮긴다. 그래서 첫 컷을 뺀 나머지 컷 길이는 박자의 정수배가 되고, 각 사진 플로우 장면의 끝(퇴장 와이프 포함)도 박 위에 놓인다. 최소 컷 길이 26프레임은 유지한다. 박자 격자는 소수 프레임이라 컷 위치는 정수 프레임으로 반올림되어 최대 ±0.5프레임(약 17ms) 어긋난다.

박자 격자가 영상 전체 시간축 기준이라, 각 장면이 영상 어디서 시작하는지(`ChapterSpec.at`)를 계획 함수들이 넘긴다. 사진 플로우가 아닌 장면(인트로·카드 등)은 길이가 고정이라 박에 맞지 않는다. 박자 맞추기를 켜면 영상이 최대 장면당 1박 정도 길어질 수 있다.

## 스튜디오

왼쪽 폼 맨 위 "음악" 섹션.

1. 음원 올리기(MP3·WAV·M4A·OGG, 60MB 이하). 파일은 `.studio/uploads/`에 저장된다. 서버 형식 검사는 파일 머리(매직 바이트)까지 확인한다.
2. 브라우저(Web Audio `decodeAudioData`)가 처음 90초를 분석해 BPM과 첫 박 위치를 채운다. 스펙트럼 플럭스 온셋 곡선 → 자기상관 → 빗살 점수로 BPM(0.05 단위)과 위상을 찾는다. 합성 음원(120·128 BPM 킥)에서 BPM 오차 0.03 이하, 위상 오차 약 2ms였다. 결과는 항상 수정할 수 있고 "자동 값으로" 버튼으로 되돌린다.
3. 음량, 페이드, 시작 위치, 반복, "사진 컷을 박자에 맞추기".
4. **"상업적 이용 권한이 있는 음원입니다"를 체크해야 음악이 든 MP4를 만들 수 있다.** 미리보기는 체크 없이도 된다. 서버도 `audioLicensed: true` 없이 음악이 든 렌더 요청을 거부한다. 체크 상태는 음원별로 이 브라우저에만 기억된다. 이 체크박스는 확인 절차일 뿐 권리를 보증하지 않는다.

음원은 저장소에 넣지 않는다. 시험용 음원은 python으로 합성한 WAV를 쓴다.

## 한계

- BPM 자동 분석은 박이 뚜렷하고 템포가 일정한 곡에서 맞는다. 템포가 변하는 곡, 박이 약한 앰비언트, 박자가 3/4·변박인 곡은 틀리거나 반 박·배 박으로 잡힐 수 있어 수동 수정이 필요하다. 브라우저가 디코딩하지 못하는 형식(예: 일부 M4A)은 분석이 건너뛰어지고 BPM을 직접 입력해야 한다.
- `loop`로 반복할 때 음원 길이가 박자의 정수배가 아니면 반복 지점에서 박이 어긋난다(컷 격자는 음원이 한 번도 끊기지 않았다고 가정). 반복 지점이 박에 맞도록 잘린 음원을 권한다.
- 가변 BPM·박자 이동은 지원하지 않는다(BPM 하나, 위상 하나).
- 효과음(컷 전환음 등)은 아직 없다. 배경 음악 한 트랙만 지원한다.
- 설정 내보내기 JSON의 `audio.src`가 `/uploads/…`이면 스튜디오 서버가 있는 환경에서만 유효하다. 명령줄 렌더(`scripts/render.mjs`)에는 음원을 `MEDIA_DIR`(public) 안에 두고 상대 경로로 지정한다.
- 미리보기 재생은 브라우저 자동재생 정책상 사용자가 재생 버튼을 눌러야 소리가 난다.
