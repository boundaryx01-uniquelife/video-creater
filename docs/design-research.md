# 디자인 레퍼런스 — 숫자로 확인되는 것만

목표는 **어떤 조건에도 대응하는 영상 제작기**다. 레퍼런스는 사용자가 고른 예시가 아니라 **판매 수·사용 수·수상·조회수가 확인되는 것**에서 가져오고, 화면을 베끼지 않고 원칙(구성·리듬·글자·움직임)만 쓴다.

1차 조사(2026-11 초)는 업체 트렌드 블로그 위주라 폐기했다. 이 문서는 2차 조사 결과다. 원자료: [A 한국 학교·공공기관 영상](research/A-korean-school.md), [B 템플릿 플랫폼](research/B-templates.md), [C 수상·큐레이션](research/C-awards.md).

## 증거 등급과 한계

| 등급 | 뜻 |
|---|---|
| A | 같은 숫자가 서로 다른 검색 결과 2곳 이상에서 확인 |
| B | 플랫폼·시상 공식 페이지 문구가 검색 결과에 1회 확인 |
| C | 기사·자기보고·시점 스냅샷 |
| U | 라벨 불명·출처 상충 — 근거로 쓰지 않음 |

- 이 작업 환경은 youtube.com, videohive.net, capcut.com, 시상 사이트 접속이 막혀 있어 **페이지를 직접 연 확인은 0건**이다. 모든 숫자는 검색 결과에 인용된 페이지 문구다.
- **영상은 하나도 보지 못했다.** 컷 길이·서체 같은 세부는 설명문·기능 목록에서 추정한 것이다.
- 업체 블로그의 "트렌드" 주장은 인기 근거에서 뺐다.

## 1. 핵심 발견

1. **학교 영상의 가치는 조회수가 아니라 공유·보관이다.** 100만 회 이상 학교·교육 영상은 교사 개인 채널의 감동 기록, 예능 협업, 지자체 밈 숏폼이고, 학교·교육청의 행사 기록·소개 영상은 편당 수천~수만 회다(A, C등급). 사진 슬라이드형 행사·졸업 영상이 크게 퍼진 사례는 찾지 못했다. → 기준은 "학부모가 보고 저장하고 싶은 완성도"로 둔다. 밈 차용은 학교 맥락에서 위험(삭제 사례 있음).
2. **돈을 내고 사는 사진 영상 1위는 감성 슬라이드쇼다.** VideoHive 판매: Dreamy Lovely Slideshow 1,081(B), Bright Slideshow 823(A), Parallax Slideshow 462(A), Lovely Slides 444(A). 졸업 전용은 최대 148(B)로 약하다.
3. **무료 템플릿은 포토 덤프·N장 결산·졸업이 강하다.** CapCut 사용 수: 2025 Recap 100장 6.2만(B), GRADUATION 5.4만(B), Photo dump 4.3만(A), Graduation Template 3.8만(A).
4. **수상작은 "한 컷에 한 사실"이다.** Spotify Wrapped(Cannes Gold Lion 2023, B), Google Year in Search 2019(Webby, B), Nike Your Year(D&AD Wood Pencil, B), Apple Shot on iPhone(Cannes Outdoor GP 2015, B), Cambridge "Dear World… Yours"(D&AD Graphite, B).
5. **짧은 판 + 긴 판이 표준이다.** Lovely Slides 1:19 / 2:32, Dreamy Lovely 짧은 판 33초(B).

## 3. 계열과 상관없는 원칙 (수상작·상위 템플릿 공통)

1. **영상 전체를 한 문장으로 요약할 수 있게**: "Thanks 2016", "Dear World… Yours"처럼 개념 하나.
2. **한 컷에 한 사실**: 숫자 하나, 문장 하나, 질문 하나.
3. **형식을 고정하고 내용을 바꾼다**: 같은 카드·같은 자막 틀의 반복이 신뢰와 리듬을 만든다.
4. **사진이 주인공이면 글자는 작게, 글자가 주인공이면 사진 없이 색면**: 둘을 같은 크기로 다투게 하지 않는다.
5. **음악이 쌓이고 터진 뒤 정리**: 후반에 컷을 빠르게, 마지막은 느리게 닫는다.
6. **짧은 판과 긴 판**: 30–40초 공유용 + 1–2.5분 본편.
7. **사진 수가 곧 형식**: "사진 10장", "100장" 같은 장수별 구성. 장수에 맞는 계열·부품을 고른다.

## 4. 새 구조 부품 후보

- `compare.then-now` — 그때와 지금 두 장 비교 (CapCut 약 59만, U — 숫자 라벨 불명이라 우선순위 중간)
- `montage.uniform` — 같은 간격 몽타주
- `card.stat` 변형 — 결산 카드 계열의 숫자 한 장
- 2.5D 패럴랙스 움직임 — 사진 한 장을 확대 비율 차이로 깊이감 (VideoHive 462·444·284; 정교한 인물 분리는 하지 않음)

## 5. 판단 규칙 (설계도 초안)

| 조건 | 기본 선택 |
|---|---|
| 졸업·추억·학년 말, 감동 | 감성 슬라이드쇼 (+ 결산 카드 몇 장) |
| 학년 말·행사 결산, 숫자 있음 | 결산 카드 |
| 아이들·체험학습·학급, 따뜻하게 | 스크랩북 |
| 학교·기관 소개, 공식적 | 에디토리얼 |
| 공식 행사 기록, 시간순 | 다큐 |
| 축제·운동회, 신나게 / 예고 | 박자 컷 프로모 |
| 같은 구도 사진이 많음 | 등속 몽타주 부품 |

AI는 사진(색, 실내·야외, 인물 수, 장수, 분위기)을 보고 바꿀 수 있다.

## 6. 다시 확인할 것

접속 허용(youtube.com, videohive.net, capcut.com, 시상 사이트) 시 B등급을 A로 올리고 미리보기 설명을 확인할 수 있다. 영상 자체를 보고 컷 길이·서체를 재는 것은 사람이 해야 한다.
