# 졸업 영상: 촬영 날짜로 자동 구성

졸업 영상(`grad`)의 학년 챕터·월별 타임라인·카드 수치·아웃트로 숫자를 사진의 촬영 날짜(EXIF DateTimeOriginal)로 채운다. 샘플에 직접 입력돼 있던 값(`gradSample()`)을 사진에서 계산한 값으로 바꾸는 기능이다.

## 파일

| 파일 | 역할 |
|---|---|
| `src/modes/schoolYear.ts` | 순수 함수 `planGrad()`. 학년 분류, 월별 counts, bands/marks, 대표 사진 선정, 자막, 통계 |
| `src/modes/gradCompose.ts` | `composeGrad()`. 계획을 `ModeVideoProps`에 반영(순수 함수) |
| `src/studio/GradAuto.tsx`, `gradAuto.css` | 스튜디오 패널. `StudioApp.tsx`에는 import 1줄과 마운트 1줄만 있다 |
| `scripts/test-grad-auto.ts` | 단위 검증 |

검증: `node --experimental-strip-types scripts/test-grad-auto.ts` (`TZ=UTC` 등으로 시간대를 바꿔도 같은 결과).

## 규칙

- **학제**: 3월 1일에 학년이 바뀐다. 2월 말일(윤년은 29일)까지가 이전 학년. 입학 학년도 = 입학일의 달력 연도(2월 입학 오리엔테이션도 그해 학년도).
- **범위**: 입학일 ~ 졸업일, 양 끝 포함(날짜 단위, 촬영 시각의 현지 달력 날짜 기준). 졸업일이 마지막 학년 말(2월 말일)을 넘으면 그날까지만 쓰고 경고한다.
- **기타(제외)**: 입학 전 사진, 졸업 후 사진, **촬영 시각이 없는 사진**. 날짜를 추측하지 않고(파일 순서·수정 시각으로 보정하지 않음) 개수만 알린다. 영상·타임라인·통계에는 들어가지 않는다.
- **D+n**: 입학일 당일이 D+1. 총 일수 = 졸업일의 D+n (예: 2024-03-04 ~ 2027-02-12 = 1,076).
- **counts**: 입학 월 ~ 졸업 월(36개월)의 월별 장수. 사진 없는 달은 0. 합계 = 범위 안 사진 수. bands는 학년별 월 구간, marks는 행사 월 위치.
- **marks 선택**: 같은 달·가로로 겹치는 라벨은 뺀다(렌더러의 위아래 번갈아 배치를 그대로 계산). 주요(★) → 사진 많은 순으로 우선. 뺀 행사는 패널에 알린다.
- **학년별 대표 사진(챕터당 기본 10장)**: ① 행사별로 행사일 ±1일(기간 행사는 기간 ±1일) 안에서 점수 최고 1장 ② 남는 자리는 학년 기간을 균등 분할해 구간별 점수 최고 1장(같은 날·10분 이내 연사는 피함) ③ 첫 장(챕터 대표)은 점수 높은 가로형, 나머지는 시간순.
- **점수**: 품질 점수(`score`)가 있으면 그것 + 행사 근접 보너스. 없으면 가로형(0.3) + 행사일 근처(0.3). 스튜디오는 아직 품질 점수를 계산하지 않으므로 항상 후자.
- **자막**: 모든 선택 사진에 날짜 칩(`2024.03.04`). 행사 대표 사진에는 행사명과 `D+n`.
- **챕터**: 사진이 없는 학년은 챕터를 만들지 않는다(카드 번호는 `03 / 03`처럼 학년 기준, 레일은 3학년 전체 표시). 한 장도 없으면 구성하지 않고 안내한다. 기존 챕터의 컷 속도·데이터 장면(담임 한마디 등)은 같은 학년에 이어 쓴다.
- **아웃트로**: 졸업생 수는 입력값, 함께한 날·사진 수는 계산. 인트로 칩(입학·졸업·졸업생)과 아웃트로 rows(입학·졸업)도 같이 갱신한다.

## 패널 사용

1. 입학일·졸업일·졸업생 수·행사 표를 채운다(값은 브라우저에 저장됨).
2. **사진 선택**: 촬영 날짜와 가로세로비만 읽는다(업로드 없음, 수천 장도 가능). 학년별 장수와 "범위 밖 N장"이 바로 보인다.
3. **자동 구성 실행**: 선택된 사진(학년당 N장)만 서버에 올리고 props를 갱신한다.
4. **자동 구성 취소**: 실행 직전 props로 되돌린다(한 단계, 이 페이지를 닫으면 사라짐). 실행 후 직접 고친 내용도 함께 되돌아가므로 확인창이 뜬다.

## 한계

- 촬영 시각이 없는 사진은 쓰지 않는다. 카메라 시계가 틀렸거나 메신저로 받아 EXIF가 지워진 사진은 날짜 분류가 안 된다.
- 사진 품질(선명도·눈 감김 등)은 보지 않는다. 가로형·행사일 근처 규칙뿐이다.
- EXIF 시각에는 시간대가 없어 브라우저 현지 시각으로 해석한다.
- 학제는 3월 1일 시작 3년 과정(고교·중학교)이 기본이다(`years`로 1~6 지정 가능하나 패널은 3 고정).
- 학년당 선택 장수가 많아도 영상 흐름 장면은 길이 상한(약 6초)까지만 쓴다.
