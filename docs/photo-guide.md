# 사진 보내는 법 (선생님용 한 장 안내)

영상은 사진이 좋아야 잘 나옵니다. 아래만 지켜 주시면 됩니다.

## 꼭 지켜 주세요
1. **행사 하나 = 폴더 하나**
   폴더째로 알려 주시거나 zip 파일로 주세요. 여러 행사를 한 폴더에 섞지 않습니다.
2. **원본 파일 그대로**
   카카오톡 등 메신저로 주고받은 사진은 촬영 시각이 지워지고 화질이 낮아집니다. 그러면 활동 순서와 구분을 추측해야 합니다.
   - 휴대폰 → PC: 케이블, 클라우드(원본 화질), 메신저의 "원본" 옵션
   - 여러 선생님이 찍은 사진을 모을 때도 같은 방법으로 받아 주세요
3. **파일 이름은 바꾸지 않습니다**
   원래 이름에 촬영 순서와 시각이 들어 있습니다.
4. **동의하지 않은 학생이 나온 사진은 넣지 않습니다**
   초상권·개인정보 동의가 없는 학생이 나온 사진은 처음부터 폴더에 넣지 않는 것이 가장 안전합니다. 넣었다면 번호로 알려 주세요.

## 이렇게 하면 더 좋습니다
- **20–40장**이 알맞습니다. 잘 나온 것만 고르실 필요 없습니다. 비슷한 사진·흔들린 사진은 알아서 뺍니다.
- **단체 사진, 가까이서 찍은 사진, 작품·장소 사진**이 섞여 있으면 영상이 풍성해집니다.
- **활동별 하위 폴더**를 만들어 두시면 그대로 활동 구분으로 씁니다. 폴더 이름이 활동 이름, 앞 숫자가 순서입니다.
  ```
  5월 체험학습/
    1 박물관 관람/
    2 점심/
    3 토기 만들기/
    메모.txt
  ```
- **메모.txt**에 적어 두시면 다시 묻지 않습니다.
  ```
  한빛초 3학년 2반 박물관 현장체험학습
  학부모 알림장 공유용, 1분 이내
  단체 사진은 꼭 넣어 주세요
  마지막에 "함께해 주셔서 감사합니다" 넣어 주세요
  ```

## 지금은 안 되는 것
- 동영상 파일(사진만 씁니다)
- 원하시는 특정 곡 넣기는 사용 권한(상업적 이용 포함)이 확인된 음원 파일을 주셔야 합니다. 기본으로는 이 프로그램이 직접 만든 배경 음악 3곡(밝게·따뜻하게·차분하게) 중 하나가 들어갑니다
- 얼굴 가리기·사진 보정

## 영상을 받은 뒤
좋았던 점과 고칠 점을 말로 알려 주세요. 미리보기 이미지에 장면 번호가 있으니 "3번 장면 자막이 어색해요"처럼 번호로 말씀해 주시면 정확히 고칩니다. 알려 주신 취향은 기록해 두고 다음 영상부터 반영합니다.
