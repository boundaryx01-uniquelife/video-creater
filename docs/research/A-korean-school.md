## 0. 먼저 밝히는 한계 (중요)

- **WebFetch가 전부 차단됨.** youtube.com, dhnews.co.kr, twig24.com, dgmbc.com, seoul.co.kr, asiae.co.kr 모두 `getaddrinfo ENOTFOUND`(세션 네트워크 허용 목록 밖). 따라서 **YouTube 페이지에서 조회수/업로드일을 직접 확인한 항목은 0건**이다. 아래 "검증됨(1)" 범주는 비어 있다.
- 모든 수치는 **WebSearch 결과 요약에 인용된 뉴스 기사 수치**(범주 2)이거나 **출처 불명/상충 수치**(범주 3)다. 기사 원문 전체도 읽지 못했고 검색 요약 속 인용구에 의존했다. 요약기가 서로 다른 검색에서 상충하는 정보를 낸 경우(아래 표시)가 있어 원문 대조가 필요하다.
- **영상 자체를 보지 못했다.** 제작 기법 칸은 모두 기사·설명 텍스트 기반 "추정"이며, 영상에서 확인한 것이 아님. 허용 목록에 youtube.com 및 위 뉴스 도메인을 추가하면 재검증 가능.
- 조회수는 시점 의존적이다(같은 영상이 매체별로 524만/540만/600만/634만으로 보도됨). 업체가 KPI용 조회수를 사는 관행이 있다는 칼럼도 있어(i-boss 계열 칼럼, 단일 출처) 공공기관 수치는 특히 주의.
- 업체 블로그/템플릿 사이트(캡컷, 필모라, VEED 등)의 "졸업영상 만드는 법"은 인기 증거로 채택하지 않았다.

- 확인된 사실(인터뷰 인용): 기획·출연·촬영·편집을 1인이 직접, 편집 독학(파이널컷 프로), 제작비 연 61만원 수준(주로 편집 프로그램). "돈 들인 티는 나는데 조회 수는 안 나오더라"며 비싼 제작을 피했다고 발언. 바이럴을 직접 목표로 기획해야 한다고 언급.
- 분석 글(위픽): 러닝타임이 짧고 영상 하나에 메시지 하나, 유행 편집·자막 포인트와 밈을 타이밍 맞게 사용.
- 구조(추정): 밈/패러디 포맷에 공익 메시지 얹기(관짝춤+거리두기, 범죄와의 전쟁+악성민원, 추노). 공개 직후 속도가 관건.

### "학생을 울렸습니다" (#2)
- 근거: 한교닷컴, 대구MBC 인터뷰. 교사 발언: "요즘 교실의 이미지가 교권침해·학폭 등으로 나쁜데 진짜 교실을 꾸밈없이 보여 주고 싶었다."

- 효과 요인(추정): 서사(수술 후 복귀 친구) + 반 아이들의 실제 반응.

### 학끼오TV (#13), 울산교육청 (#15)

**정지 사진 + 텍스트 + 음악으로 재현 가능한 것**
- 한 영상 한 메시지, 짧은 길이, 후반부 반전 구조(마지막 컷에서 의미 전환)를 사진+자막으로 구성.
- 서사 구조(상황 -> 감정 -> 반응) 를 사진 순서로 구성한 "연속 사진 스토리", 문구 한 줄 자막으로 반전/유머 전달(밈 자막 문법은 일부 가능).
- 졸업·감동형은 음악+사진+이름 자막이 기본이나, 단독으로 고조회를 만든 근거 수치는 이번 조사에서 확보하지 못함(범주 3 수준).
- 이름/날짜/숫자 같은 타이포 중심 구성 (학교 이름 카운트다운, "N년 전 입학 vs 오늘" 전후 비교 사진 쌍).

**전이되지 않는 것**
- 실시간 인물 반응·표정·대사(#2의 핵심), 군무(#11), 몰카 서프라이즈(#13), 패러디 연기(충TV), 유명 아이돌 출연(#4, #12), 영상 편집의 컷 타이밍 중 움직임 의존 요소.
- 인물 의존형 채널 운영(충주맨)의 지속성과 개성.
- 초상권·개인정보: 교사 몰카처럼 개인이 특정되는 영상, 성 대상화 논란(경남교육청 밈) 등은 학교 맥락에서 리스크.

## 6. 핵심 결론 (정직한 평가)

- 학교·교육 영상 중 100만 이상은 대부분 **교사 개인 채널의 진정성 콘텐츠**, **예능 협업**, **밈형 지자체 숏폼**이며, 학교·교육청 공식 "행사 기록/소개 영상"은 편당 수천~수만에 그친다는 증거(#15, #16)가 있다. 즉 사진+텍스트 기반 행사 영상의 수요는 "공유·보관·학부모용"이지 "조회수 바이럴"이 아닐 가능성이 높다. 바이럴 레퍼런스로 삼기엔 근거가 약하다.
- 이번 조사에서 "정지 사진 슬라이드 졸업 영상"이 고조회를 낸 증거는 **한 건도 확보하지 못했다**. 존재하지 않는다고 단정은 못 하지만, 이 부분을 가정한 설계는 위험.
