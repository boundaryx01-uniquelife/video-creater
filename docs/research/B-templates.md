# B. 사진 기반 영상 템플릿 플랫폼 — 수치로 확인 가능한 인기 포맷

작성일: 2026-11-15 / 담당: Strand B

## 0. 먼저 밝히는 한계 (중요)

- **직접 페이지를 열어 확인하지 못했다.** 이 세션에서 WebFetch는 videohive.net, capcut.com, freevisuals.net 모두 DNS 단계에서 막혔고 (`getaddrinfo ENOTFOUND`), curl도 프록시 403이다. 따라서 "내가 페이지에서 직접 확인(verified)"한 수치는 **0건**이다.
- 모든 수치는 **WebSearch 결과 요약문이 인용한 플랫폼 자체 페이지의 텍스트**(VideoHive 아이템 페이지의 "Cart N sales", CapCut template-detail의 "N uses")다. 출처가 벤더 블로그가 아니라 플랫폼 원본 페이지라는 점에서 약한 증거보다는 강하지만, 검색 요약기를 거쳤으므로 오독 가능성이 남는다. 이 문서에서는 다음과 같이 등급을 나눈다.
  - **A등급 (플랫폼 원본 페이지 수치, 검색 결과에 인용됨, 2회 이상 교차 확인)**: 같은 수치가 서로 다른 검색에서 반복 확인된 것.
  - **B등급 (플랫폼 원본 페이지 수치, 1회 인용)**
  - **C등급 (제3자 보고)**: 블로그/타사이트가 전한 수치. 인기 근거로 쓰지 말 것.
  - **U (미확인/의미 불명)**: 숫자의 의미(조회/사용/좋아요)가 페이지에 명시되지 않음.
- 수치는 모두 **스냅샷 날짜 불명 또는 인덱싱 시점**이다. VideoHive 판매수는 누적 판매량(라이프타임)이고, CapCut "uses"는 템플릿 사용 횟수다.
- 다음 단계 권장: videohive.net, capcut.com 을 네트워크 허용 목록에 추가하면 아래 표의 A/B등급 항목을 원본에서 직접 재확인하고 프리뷰 영상 구조까지 읽을 수 있다.
- **형식(구조/리듬/타이포) 서술의 대부분은 검색 요약에 나온 기능 목록(placeholder 수, 길이, 버전)에서만 얻은 것**이다. 프리뷰 영상은 보지 못했다. 추정한 부분은 "(추정)"으로 표시했다.
- Canva, 미리캔버스, VLLO, Adobe Express, Instagram/Edits는 **공개 사용 횟수가 없거나(Canva/Adobe는 '조회순 정렬'만 있고 수치 비공개) 확인되지 않았다.** 이 플랫폼들에서는 수치 근거를 못 얻었다는 것 자체가 결과다.

### 1-C. 수치가 없거나 확인 못 한 플랫폼 (정직한 보고)

- **Canva**: 공개 사용 횟수 없음. 슬라이드쇼 카테고리는 "314개 중 50개 표시" 같은 템플릿 총수만 보인다. 한국어 영상 템플릿 1,565개. 인기도 수치 근거 못 얻음.
- **Adobe Express**: "Most Viewed" 정렬은 있으나 조회수 비공개.
- **Motion Array**: 다운로드/판매 수 비공개(리스팅에 표시 안 됨). 구조 서술만 얻음 (예: Photo Memories Slideshow — Motionscore: 느리고 시네마틱, 라이트릭 + 단순 텍스트 + 부드러운 전환 / FXBox: 사진 프레임 + 4096x2304 세로 가로 양쪽 / Zhoomart: 69 media + 25 text / JuliaDesign(Premiere): 10 media + 10 text).
- **Envato Elements**: 개별 아이템 수치 못 얻음.
- **Instagram Reels / Edits**: 템플릿별 "uses" 공개 수치를 담은 출처를 찾지 못함. 블로그들은 모두 정성적.
- **TikTok**: 템플릿별 수치는 CapCut 쪽 페이지에 노출되는 것으로 대체됨.
- **미리캔버스 / VLLO / 한국 기사**: 인기 순위나 사용 횟수를 공개한 출처를 찾지 못함. VLLO는 "수백 개 템플릿, 사용자 제작 공유"라는 공식 설명만 확인. 한국 CapCut 페이지의 "만" 단위 표기가 유일한 한국어 수치지만 의미가 불명(U).

## 2. 벤더 트렌드 블로그 주장 (인기 근거에서 제외)

CapCut/Filmora/NemoVideo/Pippit 블로그의 "트렌드 템플릿" 서술, 필모라의 "Ical 81만, 인스타 트렌딩 37만"(11~12초 일반 템플릿이라 사진 슬라이드로 보기 어려움)은 C 또는 U로 처리하고 순위에 쓰지 않았다.

## 3. 반복되는 패턴 (수치 상위 항목 기준, 일부는 추정)

주의: 이 절은 (a) 아이템 제목/기능 목록/설명문에서 확인된 사실과 (b) 그 위의 추정을 구분한다. 프리뷰 영상은 확인하지 못했다.

### 3-1. 확인된 사실 (수치 항목에서)

1. **사진 장수는 짧은 것과 긴 것의 2버전이 보편적**: Lovely Slides는 1:19(주요 23장) / 2:32(48장), Dreamy Lovely는 33초(5장) 짧은 버전. 즉 "짧은 형(약 30~40초) + 긴 형(1~2.5분)"이 관행.
2. **CapCut은 "필요 클립 수"가 곧 템플릿 정체성**: 1, 4, 5, 10, 11, 16, 17, 41, 60, 100, 300. 사진 장수를 제목에 넣는 관행(2 photos, 10 photos, 100 photos, 300 photos).
3. **연말 회고 / 졸업 / 여행이 사진 템플릿의 3대 주제**로 보인다 (CapCut 목록 상위 + VideoHive에 졸업·여행 전용 항목 존재). 단 졸업 VideoHive 판매량은 148 이하로 낮음 — 수요는 웨딩/로맨틱 감성형(1,081)과 일반 슬라이드쇼가 더 큼.
4. **패럴랙스(레이어 깊이감)** 슬라이드쇼가 VideoHive 상위에 반복(462, 284).
5. **비트 동기 오프너** (Percussion Dynamic Opener 114, "BEAT 5 ẢNH CHÁY" 21.1만).
6. **CapCut의 좋아요/사용 비율이 높은 것은 소량 클립 + 디자인된 룩(예: GRADUATION PICS 4클립, 43%)**. 장수 긴 템플릿(100장, 300장)은 사용은 많아도 비율이 낮다. 비교는 참고용.

### 3-3. 구조 파트 (재사용 단위)

- **오프너**: (1) 타이틀 + 연도/행사명 큰 글자, (2) 빠른 사진 플래시 오프너(비트), (3) 슬로우 줌 인 단일 사진 오프너, (4) 잉크/브러시 와이프 오프너(Ink Opener, Wedding Brush 계열 존재 확인; 판매수 미확인).
- **본문 사진 레이아웃**: 단일 풀프레임, 프레임/액자(Photo Frames), 폴라로이드, 필름 롤, 롤/스크롤 콜라주, 3~5장 비트 분할, 2분할 전/후.
- **전환**: 디졸브/크로스페이드(로맨틱), 패럴랙스 슬라이드, 비트 컷, 롤 스크롤, 필름 와이프.
- **엔딩**: 타이틀 카드/로고 정리, 날짜 또는 "Thank you 2025" 문구 카드 (CapCut 목록에 THANK YOU 2025 확인; 수치 미확인).
- **길이**: 20~40초 짧은 쇼츠형 + 1~2.5분 긴 형의 2버전.

### 3-4. 정지 사진 + 글자 + 음악만으로 가능한 것

가능: A, C, D, E, F, G, H 전부, 그리고 B의 단순화(스케일 차이 팬).
불가/별도 소스 필요: 사진 속 인물 분리 레이어 정교 합성, 실사 영상 클립이 섞이는 템플릿(포토+비디오 혼합 요구), 3D 폴더/카메라 리그의 완전한 재현.

## 4. 제품 설계에 시사점 (수치 기반, 신뢰도 한정)

1. 수치 가장 큰 것은 "감성 슬라이드쇼"와 "N장 연말 회고/포토 덤프"다. 둘 다 정지 사진만으로 가능하다.
2. 장수별 템플릿(짧은 3~5장, 10장, 17장, 100장)과 "짧은/긴 2버전" 지원이 시장 관행이다.
3. 졸업/기관 소개용은 VideoHive 판매수가 낮다(최대 148). 틈새이므로 "감성 슬라이드쇼"의 변형으로 접근하는 편이 수요에 맞다. 단 CapCut에서 졸업 템플릿 사용 횟수는 5만 단위로 꽤 크다.
