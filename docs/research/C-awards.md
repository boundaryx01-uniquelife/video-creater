# Strand C — 수상·큐레이션 모션/영상 레퍼런스 (사진+타입 중심 영상)

작성일: 2026-11-15 / 범위: D&AD, Cannes Lions, One Show, ADC, Webby, Clio, Emmy(타이틀), Vimeo Staff Pick, 대한민국광고대상, 서울영상광고제 등

## 0. 방법과 한계 (먼저 읽을 것)

- WebSearch 약 32회 실행. 제목은 "수상 사실 확인됨"이 아니라 "검색 결과에 어떤 문구로 나왔는가"로 구분했다.
- **WebFetch는 이 세션에서 외부 도메인 전부가 DNS 차단**되어 있었다 (winners.webbyawards.com, lovethework.com, dandad.org, youtube.com, newsroom.spotify.com 모두 `ENOTFOUND`). 그래서 "수상 사이트 페이지를 직접 열어 확인"은 **한 건도 못 했다.** 이 도메인들이 허용되면 아래 "검증 상태"의 B등급 항목을 바로 A로 올릴 수 있다.
- 따라서 신뢰 등급을 이렇게 둔다.
  - **A (직접 확인)**: 해당 없음. 이번 세션에서는 0건.
  - **B (공식 DB 항목이 검색 결과에 노출 + 검색 요약이 수상/수치를 서술, 직접 페이지는 못 염)**: 수상 DB 페이지(D&AD/One Show/ADC/Cannes/Webby/Emmy) 또는 언론 다수가 동일하게 보도.
  - **C (보도/자기보고)**: 출품 텍스트에 적힌 조회수(출품자 자기보고), 위키 스냅샷 수치, 개인 포트폴리오 주장.
  - **U (미확인)**: 찾지 못했거나 상충.
- **조회수는 모두 "특정 시점 스냅샷"**이다. 현재 YouTube 값은 확인 못 했다. 숫자를 UI/문서에 쓸 때는 시점을 같이 적을 것.
- **크래프트 설명의 출처**: 영상 자체를 보지 못했다(영상 시청 불가). 크래프트 서술은 (a) 검색 결과 텍스트에서 뽑은 사실, (b) 내가 기존에 알고 있는 작품 지식을 근거로 한 것이다. 각 항목에 `[텍스트 근거]` / `[기억 기반·미시청]` 로 표시했다. 기억 기반 부분은 구현 전에 영상으로 재확인 필요.
- 벤더 트렌드 블로그(템플릿 회사 글 등)는 근거에서 제외했다. 검색에서 나온 Envato/Artlist/b2w 류는 인용하지 않는다.

**1. Google — Year in Search 2014** (Google, 2014)
- URL: 공식 YouTube "Google - Year In Search 2014" (video id는 확인 못 함). 근거 기사: https://ibtimes.com.au/youtube-video-google-year-search-2014-featuring-robin-williams-world-cup-beyonce-iphone-6-ebola-goes
- 인정: IBTimes AU가 "게시(2014-12-15) 이후 1,700만 뷰 이상" 보도. 영상 길이 92초. **C등급** (기사 시점 스냅샷, 현재값 아님). 수상은 못 찾음 → U.
- 크래프트 [텍스트 근거+기억 기반]: 실제 검색어를 화면 중앙 검색창에 한 글자씩 타이핑 → 해당 사건의 뉴스/UGC 영상으로 컷. "In 2014 we searched trillions of times"로 시작. 구조는 "검색어 → 사건 클립" 반복의 카탈로그형, 클라이맥스에 감정적 사건(Robin Williams 등)을 배치. 타이포는 Google 검색창 UI 자체(산세리프, 흰 배경), 텍스트가 곧 내비게이션 장치. 음악은 서정적 피아노/스트링 빌드업 후 컷 속도를 올림. (음악·컷 속도는 기억 기반)

## 3. 반복되는 크래프트 원칙 (위 항목에서 추출)

1. **하나의 개념 프레임**: "heroes"(YiS 2019), "why"(YiS 2020), "Dear World… Yours"(Cambridge), "Thanks 2016"(Spotify). 영상 전체가 한 문장으로 요약된다.
2. **한 컷 = 한 사실/한 메시지**: Wrapped 카드, YiS 검색어 한 줄, Spotify OOH 한 문장. 텍스트를 한 컷에 하나만 둔다.
3. **정형 구조의 반복**: 검색창 타이핑(YiS), 카드 슬라이드(Wrapped). 형식을 고정하고 내용을 바꿔 신뢰·리듬을 만든다.
4. **사진이 주인공일 때 텍스트는 크레딧급 크기**(Shot on iPhone) / **텍스트가 주인공일 때 사진 없이 색면**(Thanks 2016, Wrapped).
5. **등속 리듬 + 정렬**(Everyday): 변화에 집중하게 하려면 컷 길이를 고정하고 피사체 위치를 맞춘다.
6. **음악 빌드 → 클라이맥스 후 정리**: YiS, 어프터무비, 연말 결산 공통. 컷 속도를 후반에 올린다.
7. **3막 회고**: 회고 → 숫자 → 다음 목표(Nike Your Year).
8. **제약이 스타일이 된다**: Spreadbeats(엑셀), Catch Me(Saul Bass 평면색), 이중노출(True Detective).

> 위 1~8 중 1·2·3·4·5·6·7은 검색 텍스트로 뒷받침되는 사실이 포함돼 있고, 컷 속도·서체 등 세부 수치는 영상 시청 없이 단정할 수 없어 일반 원칙 수준으로만 썼다.

## 4. 스타일 패밀리 (사진+텍스트+음악만으로 구현 가능 여부 포함)

### F1. 검색창/카탈로그형 회고 (Google YiS 계열)
- 토큰: 흰/아주 밝은 바탕, 둥근 모서리 검색창 UI, 산세리프(Product Sans 류), 단색 포인트 1개.
- 모션 곡선: 타이핑은 등속, 사진 전환은 짧은 크로스컷(0.2~0.4s) 위주. 켄번스 느림.
- 컷 리듬: 질문 한 줄 + 사진 1~2장, 후반 빠르게 가속.
- 질감: 깨끗함, 필름 그레인 없음.
- 적합 용도: 연말·연간 결산, 졸업 회고, 기관 연간 보고. 
- **사진+텍스트+음악만으로 가능: 예.** (검색어를 "질문/주제어"로 대체)

### F2. 풀컬러 카드 스택 (Spotify Wrapped 계열)
- 토큰: 고채도 단색 배경 3~5색, 초대형 산세리프(굵기 700~900), 숫자·한 문장, 사진은 원형/사각 박스 1개.
- 모션 곡선: 스케일/슬라이드 인, 이징 빠른 시작-느린 끝(ease-out), 지속 0.3~0.5s.
- 컷 리듬: 카드당 3~5초, 박자 맞춤.
- 질감: 플랫, 그라디언트 최소.
- 적합 용도: 데이터/연간 하이라이트, 행사 결산, 동아리·학급 통계.
- **가능: 예.** 사진 비중 낮고 타입 비중 높음.

### F3. 사진 풀블리드 + 극소 캡션 (Shot on iPhone 계열)
- 토큰: 사진 100% 풀블리드, 흰/검정 소형 캡션(하단), 효과 없음.
- 모션: 켄번스 매우 느림(스케일 1.00→1.06), 컷은 디졸브 또는 직컷.
- 리듬: 4~6초/컷, 곡 흐름에 맞춰 일정.
- 적합: 이벤트 하이라이트, 졸업 앨범, 기관 소개(사진이 좋을 때).
- **가능: 예.** 가장 제품 친화적.

### F4. 등속 몽타주 / 정렬 타임랩스 (Everyday 계열)
- 토큰: 동일 구도 사진 다수, 텍스트 없음 또는 연도 한 줄, 피아노 단곡.
- 모션: 직컷만, 컷 간격 고정(약 0.15~0.3s).
- 적합: 성장 기록, 졸업 전후, 입학~졸업, 프로젝트 진행.
- **가능: 조건부.** 사진이 많고 구도가 비슷해야 함.

### F5. 편지/선언문 구조 + 앰비언트 사진 (Cambridge 계열)
- 토큰: 세리프 또는 인문적 산세리프, 화이트 스페이스 많은 문장, 대형 문장 한 줄 → 사진.
- 모션: 문장 페이드, 사진 느린 줌, 컷 길이 길다(5~8s).
- 적합: 기관·학교 소개, 입학/졸업 메시지, 기념식.
- **가능: 예.**

### F6. 이중노출/블렌드 타이틀 (True Detective 계열)
- 토큰: 모노톤 또는 한정 팔레트, 인물+풍경 두 사진을 블렌드, 작은 타입, 느린 팬.
- 모션: 크로스디졸브 길게(1~2s), 위치 이동 느림.
- 적합: 오프닝/타이틀 시퀀스, 다큐형 소개, 추모/기념.
- **가능: 부분적.** 블렌드 합성은 사진 2장으로 가능하나 분위기 일관성은 사진 선택에 좌우.

### F7. 평면 색면 + 이동 타입 (Catch Me / Saul Bass 계열)
- 토큰: 한정 색 3~4개, 대담한 평면 도형, 타입이 화면을 가로지름, 박자 동기.
- 적합: 이벤트 티저, 프로모션.
- **가능: 부분적.** 사진 대신 도형·색면이 필요하므로 일러스트/도형 템플릿이 별도로 있어야 함.

### F8. 드롭 가속 어프터무비 (Tomorrowland 계열)
- 토큰: 음악 빌드 → 드롭에 컷 급가속, 군중/무대 클로즈업.
- **가능: 제한적.** 영상 푸티지가 핵심이라 사진 전용에는 "드롭 구간에서 컷 길이 0.3s로 단축" 정도만.

### 사진+텍스트+음악만으로 가능한 패밀리
F1, F2, F3, F5는 바로 구현 가능. F4는 사진 수가 충분하면 가능. F6은 블렌드 렌더링이 필요. F7·F8은 부분 구현만.
