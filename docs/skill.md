# school-video 스킬 (Claude Code)

초등학교 활동 사진으로 학부모 공유용 영상을 만드는 Claude Code 스킬. 교사는 사진 폴더와 목적만 말하고, Claude가 사진을 직접 보고 고르고, 문구를 쓰고, MP4를 만든다. 완성 뒤에는 말로 고친다.

- 지침: `.claude/skills/school-video/SKILL.md`
- 도구: `tools/school-video/cli.ts` (사진 읽기·모아보기 → 구성 검증 → 장면 미리보기 → 렌더)
- 영상 디자인·길이 계산: `src/elem/` (스튜디오의 "초등 활동 영상" 모드와 같은 코드)

## 쓰는 법

1. 이 저장소를 받은 뒤 `npm install` (Node 22 이상).
2. 저장소 폴더에서 Claude Code를 연다. 스킬은 자동으로 잡힌다.
3. 이렇게 말한다: "`~/사진/5월체험학습` 에 사진 있어. 3학년 2반 박물관 현장체험학습 영상 만들어줘. 학부모님께 보낼 거야."
4. 결과는 사진 폴더 옆 `…-video/video.mp4`. 고칠 점은 말로: "점심 부분 빼고 40초로", "세로로", "제목 바꿔줘".

렌더에는 Chrome이 필요하다. 없으면 Remotion이 전용 Chrome을 내려받고, 따로 있으면 `CHROME_BIN`으로 경로를 준다.

## 스튜디오 앱과의 차이

| | 스킬 | 스튜디오(웹·데스크톱) |
|---|---|---|
| 사진 고르기 | Claude가 사진을 보고(표정·구도·내용) 고른다 | 선명도·밝기·비슷함 숫자로만 고른다 |
| 문구·자막 | 사진 내용에 맞춰 쓴다 | 사진을 보지 않고 쓴다(자막은 직접 입력) |
| 고치기 | 대화 | 말로 고치기(정해진 표현) + 폼 |
| 사진 전송 | **Claude가 보는 사진은 Anthropic으로 전송된다** | 사진은 PC 밖으로 나가지 않는다 |
| 미리보기 | 장면 모아보기 이미지 → 렌더 | 실시간 미리보기 |
| 필요한 것 | Claude Code(유료 플랜) | 설치 또는 `npm run dev` |

## 개인정보

- 스킬은 시작할 때 "학생 사진이 Anthropic으로 전송된다"는 점을 알리고 확인을 받는다. 교사가 원치 않으면 사진을 보지 않는 방식(시각으로만 구성)으로 만든다.
- 이름을 쓰지 않고, 사진에 없는 사실과 누군가의 말을 지어내지 않도록 지침에 적었다. 그래도 결과는 교사가 확인해야 한다.
- 원본 사진은 건드리지 않고, 작업 폴더(`…-video/`)에 줄인 사본과 결과만 만든다. 저장소에 커밋되지 않는다.
- 학교의 개인정보·외부 서비스 이용 지침과 보호자 동의 범위는 사용 전에 확인해야 한다(이 프로젝트에서 확인하지 못함).

## 한계

- Claude Code 기준으로만 확인했다. claude.ai 채팅·Cowork에서는 확인하지 않았다.
- 실제 아이들 사진으로는 검증하지 못했다(합성 사진만 사용). 사진 판단 품질은 실제 사진으로 확인해야 한다.
- 음악, 사진 보정·얼굴 가리기, 동영상 클립은 스킬에서 다루지 않는다.
- 렌더 한 번에 1–2분(60초·720p 기준)이 걸린다.
